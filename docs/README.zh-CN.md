## 四个滑动方向

| 方向 | 作用 |
| --- | --- |
| **左滑** | 加入「待删除」，统一确认后才移入系统回收站。 |
| **右滑** | 保留，原照片不变。 |
| **上滑** | 加入本应用「收藏」，不修改系统相册的收藏标记。 |
| **下滑** | 验证身份，保存并校验加密副本，再询问是否移除公开原件。 |

底部四个按钮与手势相同。轻点照片可放大，双指缩放。「撤销上一步」可撤回最近的本地决定，提示显示在「全部照片」旁，不遮挡按钮。已经移入系统回收站或完成私密迁移的照片，需使用各自的恢复或导出功能。

点击「扫描新照片」可加入新照片。整理进度自动保存。

## 切换语言

进入 **设置 → 语言**，选择 **简体中文 / English / Español**。首次启动默认简体中文，选择后立即生效，重启仍保留。Android 系统弹窗可能使用手机系统语言。

## 私密相册与卸载后找回

- 查看入口：**设置 → 私密相册**，使用手机锁屏密码或支持的指纹验证。切到后台或约四分钟后自动上锁。
- 可恢复的加密文件保存在 **手机存储 → Download（下载）→ 私密相册**，扩展名为 `.swpv`；切换界面语言不会更改文件夹名称。
- 加密文件密码固定为 **`123456`**，本版不能修改。它与手机锁屏密码不同，容易猜到，只适合防止随手查看。
- 确认移除原件之前，普通相册仍能看到原图。私密迁移的原件移除会请求 Android **永久删除**确认，云端、回收站和其他位置的副本不会自动清理。
- 在私密相册选择「导出到普通相册」，照片会出现在 `Pictures/SwipePhoto`，私密副本继续保留。

**卸载前请进入「设置 → 卸载保护与找回 → 校验并保存全部私密照片」，确认没有未完成项目。** 旧版导入的照片尤其需要执行此步骤。处理期间请保持应用在前台。

已成功保存的共享加密文件通常会在卸载后保留，**不会自动解密**。找回步骤：

1. 重装官方 APK，进入 **设置 → 卸载保护与找回 → 选择加密文件并找回**。
2. 在 `Download/私密相册` 选择 `.swpv` 文件。可长按多选，或使用文件选择器的「全选」。
3. 输入 **`123456`**，然后验证手机身份。
4. 到「私密相册」查看，或导出回普通相册。

卸载会清除应用内部数据，尚未成功保存到共享文件夹的私密副本会丢失。删除共享文件、恢复出厂设置或手机丢失也会导致损失，建议把整个加密文件夹另存到其他设备。普通照片相册不会显示加密文件里的照片，但文件管理器仍能看到这些文件。
