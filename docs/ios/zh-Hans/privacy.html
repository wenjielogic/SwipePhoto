适用范围

iPhone 版轻扫相册由卢文杰创作。本政策适用于 iPhone App、本支持网站，以及你主动发送到下方支持邮箱的邮件。Android 版使用不同的私密存储格式，这里的 iPhone 说明不用于描述安卓存储。

App 在设备上处理什么

App 不设账号系统、广告组件或分析追踪组件，不把照片、收藏、整理历史、私密相册内容或备份密码发送给开发者。

照片权限用于展示和整理已授权照片、请求确认后的系统隐藏或删除，以及保存从旧版加密备份恢复的照片。App 会处理这些功能需要的照片数据及相关信息，例如照片标识、日期。语言偏好、整理决定、待处理照片标识及处理结果保存在本地。

新的私密操作：系统“已隐藏”

下滑只增加一条本地队列记录，确认隐藏前，原件仍显示在系统“照片”中。确认后，iOS 修改原件的隐藏状态，不复制、不删除照片，原件仍由系统“照片”保存。

查看“已隐藏”遵循设备的 iOS 身份验证设置。轻扫相册不能直接打开或解锁该相簿；系统保护开启时，也无法列出其中的照片。卸载轻扫相册不会删除这些系统已隐藏照片，也不会取消隐藏。

旧版加密存储与备份

旧版 App 加密相册保留取回入口，需要设备身份验证。照片文件与索引经过加密，并排除在 App 自动备份之外；加密密钥通过 iOS 钥匙串保护。此存储与系统“已隐藏”是两套不同机制。

你可以将加密的 .swpios 备份导出到选定位置，并用导出时的密码导入。外部备份文件由你和所选存储提供商管理。请保留经过校验的 App 外备份及密码；卸载不会自动解密或恢复旧版照片。

你的选择、保留与删除

你可以在 iOS 设置中修改或撤销照片访问权限，在历史记录有效时撤回最近的本地决定，移出待私密项目，或在设置中重新查看已保留照片。这些操作不会删除原件。已经完成的系统隐藏需要在系统“照片”中取消，不能由 App 的撤回来逆转。

本地决定和处理记录会保留，直到通过 App 修改或随应用数据移除。旧版私密副本会保留，直到恢复并验证后移除副本，或删除 App。删除 App 会移除其应用容器内的数据，包括仍在其中的旧版加密副本；iOS 的“卸载 App”保留数据功能与“删除 App”不同，可能保留应用数据。

钥匙串项目由 iOS 单独管理，删除 App 后可能仍保留，但不能重建已经删除的加密照片文件。独立导出的备份和系统“照片”中的原件取决于你的操作及所选服务，请通过“文件”、系统“照片”或相应存储服务管理。

iCloud 和你选择的服务

仅保存在 iCloud 照片中的原件可能由 iOS 下载。开启 iCloud 照片时，隐藏状态和删除可能在设备间同步。导出的备份可能由你选择的文件提供商保存或同步。这些是你选择的系统服务，不是把照片上传给开发者。

苹果诊断、App Store 与 iCloud 服务遵循苹果的设置和政策。你选择的文件及邮件提供商按各自的条款处理信息。

支持邮件

如果你主动联系支持邮箱，我们会收到你的邮箱地址、邮件内容和你选择发送的附件，用于回复、排查问题和保留必要的支持沟通，不用于广告或邮件营销。邮件提供商会处理邮件的传递和存储。

请仅发送排查所需的信息，不要发送私密照片、加密备份、密码或验证码。支持邮件只按处理请求及必要跟进所需保留，并受适用法律义务约束。你可以来信请求访问、更正或删除支持信息；服务商备份或法律要求可能限制立即删除。开发者没有权限替你访问、删除或找回设备照片库中的数据。

本网站与 GitHub Pages

这些静态页面没有广告、分析脚本、外部嵌入媒体或由本站设置的 Cookie。不过，访问网页仍会向托管服务发送网络信息。GitHub Pages 会为安全目的记录和保存访问者的 IP 地址，包括未登录 GitHub 的访问者。

托管及相关服务数据遵循 GitHub 隐私声明。另见 GitHub Pages 数据收集说明。点击外部链接后，相关服务适用其自己的隐私处理规则。“App 不上传照片”不等于“浏览网站不产生网络日志”。
